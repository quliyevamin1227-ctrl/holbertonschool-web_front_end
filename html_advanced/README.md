# Advanced HTML

HTML-only pages for **Techium**, a fictional digital agency: the homepage is built step by step (`0-index.html` to `index.html`), plus a styleguide (`11-styleguide.html` to `styleguide.html`) and the secondary pages `article.html`, `about.html`, `latest_news.html` and `contact.html`.

Topics: HTML5 skeleton, `head` metadata and favicons, semantic tags (`header`, `main`, `footer`, `section`, `article`, `aside`, `nav`), headings, paragraphs, links, lists, quotes, tables, `details`, images, SVG icons, video, audio and iframes.
